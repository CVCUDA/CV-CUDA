v0.14.1-beta
============

Release Highlights
------------------

This patch release corrects license notices in three NVCV headers:

* ``src/nvcv/util/Version.hpp``
* ``src/nvcv/util/SymbolVersioning.hpp``
* ``src/nvcv/src/include/nvcv/detail/CudaFwd.h``

The obsolete proprietary restriction paragraphs are replaced with standard
Apache-2.0 notices consistent with the existing SPDX license identifiers.
No operator implementations or public API declarations are changed.
